# Risk Register — Wayfare

Scale: Likelihood and Impact are rated **L**ow, **M**edium or **H**igh.

| #   | Risk                                                                               | L   | I   | Mitigation                                                                                                                                                                                                                                                                                                                  | Status              |
| --- | ---------------------------------------------------------------------------------- | --- | --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| R1  | **Synthetic prices mistaken for real, live offers**                                | M   | H   | Every offer has `data_status='simulated'`, and a "Simulated" label appears on each price. There is a persistent demo banner and a "How it works" page. Provider actions open an explanation dialog instead of linking out. Fictional provider and property names are used.                                                  | Mitigated by design |
| R2  | **Inconsistent total-price calculations** (list ≠ detail, double-counted VAT/fees) | M   | H   | A single SQL `quote_stay` function is used by both search and offers. Money is integer cents. Tax is calculated once per stay. The included-tax portion is informational and never added. A TypeScript reference implementation with unit tests, plus an integration test asserting SQL ↔ TS parity for every seeded offer. | Planned             |
| R3  | **Duplicate properties / offers**                                                  | M   | M   | Unique slug and `(destination, lower(name))`. A unique offer product key. Unique `(provider, external_ref)`. The seed validator rejects properties within 30 m of each other. A future matching pipeline routes low-confidence matches to review.                                                                           | Planned             |
| R4  | **Invalid coordinates** (swapped lat/lng, in the ocean, outside SA)                | M   | M   | A DB check keeps points inside SA's bounding box. API validation rejects out-of-bounds coordinates. Seed points are jittered small distances from hand-picked land anchors. A test checks every property is within its destination radius.                                                                                  | Planned             |
| R5  | **Poor map performance**                                                           | L   | M   | Marker clustering. Map points capped at 500. Lightweight divIcons. Markers are diffed rather than recreated on hover.                                                                                                                                                                                                       | Planned             |
| R6  | **Excessive database queries / N+1**                                               | M   | M   | One statement per search page plus one for map points. Page-row enrichment uses correlated subqueries bounded by LIMIT. A pool with a sensible max size. `EXPLAIN ANALYZE` is reviewed.                                                                                                                                     | Planned             |
| R7  | **Broken or misleading filters**                                                   | M   | H   | Filters run in SQL against real columns. Unknown slugs return 400, never silently ignored. Integration tests cover each filter and combinations. The count comes from the same query (`count(*) over ()`).                                                                                                                  | Planned             |
| R8  | **Accessibility problems**                                                         | M   | M   | Semantic HTML, labelled controls, focus styles, AA contrast tokens, keyboard-usable map markers, the list as primary interface. Playwright keyboard checks.                                                                                                                                                                 | Planned             |
| R9  | **Security vulnerabilities** (SQL injection, XSS, info leakage)                    | L   | H   | Zod validation with strict unknown-key rejection. Only bound parameters; dynamic SQL limited to whitelisted identifiers. React escaping, no `dangerouslySetInnerHTML`. Helmet headers. Generic 500 messages. Rate limiting. `npm audit`.                                                                                    | Planned             |
| R10 | **Unavailable external services** (tile server down, offline)                      | M   | L   | Core features need no external service. A tile-error notice. The tile URL is configurable. The list works without the map.                                                                                                                                                                                                  | Mitigated by design |
| R11 | **Unclear provider integration permissions**                                       | H   | H   | No integrations in the MVP. `REQUIRED APIS.md` §C records each provider's gating. No adapter is built until written permission or terms allow it. No scraping.                                                                                                                                                              | Mitigated by design |
| R12 | **Accidental secret exposure**                                                     | L   | H   | `.env` is gitignored; there's a `.env.example` with placeholders. The local DB password is a non-secret dev default, documented as such. A pre-commit check that `.env` isn't tracked.                                                                                                                                      | Planned             |
| R13 | **Unnecessary complexity**                                                         | M   | M   | No auth, no Redis, no ORM, no UI kit, no state library beyond TanStack Query. ADRs justify each dependency.                                                                                                                                                                                                                 | Ongoing             |
| R14 | **Third-party licence issues** (map wrapper, images, fonts)                        | M   | M   | react-leaflet (Hippocratic-2.1, non-OSI) is avoided in favour of Leaflet (BSD-2) + markercluster (MIT). Images are original generated SVGs. Fonts are OFL.                                                                                                                                                                  | Mitigated           |
| R15 | **Date/time-zone bugs** ("tonight" off by one near midnight UTC)                   | M   | M   | All "today" logic uses `Africa/Johannesburg` via an injectable clock. Dates are plain `YYYY-MM-DD` strings with no `Date` timezone parsing. Unit tests around midnight.                                                                                                                                                     | Planned             |
| R16 | **Fresh-checkout setup fails on Windows**                                          | M   | H   | Docker Compose for PostGIS (installer alternative documented). Cross-platform npm scripts (no bash). A final audit from a clean clone.                                                                                                                                                                                      | Planned             |
| R17 | **Bleeding-edge dependency versions break tooling**                                | M   | M   | TypeScript pinned to 6.0.x for typescript-eslint compatibility. Exact versions locked by `package-lock.json`.                                                                                                                                                                                                               | Mitigated           |
| R18 | **Public OSM tile policy breach**                                                  | L   | M   | Browser-only, low-volume use. Attribution always visible. No prefetching or bulk download. Referer not stripped. A configurable provider.                                                                                                                                                                                   | Mitigated           |
